# GENEAI 3.0.6

Person details now begin with compact primary actions and a single horizontally scrollable section bar. Vital facts are ordered by life stage: birth, baptism, marriage, death and burial. Evidence lives in Sources, multilingual names in Biography, and advanced AI actions in a collapsed group under Investigation. Other facts do not repeat the five essential vital types.

Burial date and place appear in the read-only essential information card. When canonical fields are absent, saved events supply dates, approximate dates and locations. Canonical dates take precedence; a missing place can be supplied by an event matching that date, avoiding the combination of contradictory records. No missing dates are fabricated and no existing records are modified.

Tests cover saved burial values, event-only burial information, canonical date priority, matching event locations, approximate dates, missing values and life-stage ordering. Responsive Chromium checks used the actual person-detail page with fictional network fixtures at 390×844, 834×1194 and 1440×1000. Burial date was visible, the Sources tab opened its evidence panel, tabs stayed in one row, and no horizontal page overflow or JavaScript errors were observed. Temporary fixtures were removed; authenticated production data and Safari were not exercised.
